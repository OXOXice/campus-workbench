# campus-workbench

AI 应用实践项目的两个演示应用（纯前端单文件，无需后端、不收集任何个人信息）：

- `index.html` —— 「我的大学第一站」个人校园工作台
  今天要处理 / 课程表 / 校园地图 / 社交提醒 / 成绩绩点 / 快递取件
- `cet4.html` —— 四级备考助手
  今日计划 / 单词打卡 / 真题练习 / 作文模板 / 专业英语

所有数据仅保存在访问者本机浏览器（localStorage），不上传服务器。
示例课程、成绩均为演示用虚拟数据。

## 本地运行

纯静态，双击 `index.html` / `cet4.html` 即可；也可以起个静态服务器：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 测试

```bash
npm install    # 只装 jsdom，仅供测试
npm test
```

`tests/ui.test.js` 用 jsdom 真实加载两个页面并执行页面脚本，覆盖：

- XSS：用户输入不会被当成 HTML 执行
- 时区：种子提醒时间、凌晨打卡日期按本地时间算
- 跨年周次不为负
- 本地存储写入失败（无痕模式 / 写满）时有提示
- 四级专业词分类筛选真的生效
- 打卡记录与连续天数

改完 HTML 先跑一遍 `npm test`，能挡住上面这些低级回归。
